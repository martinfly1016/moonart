眠い顔文字・おやすみ顔文字コピペ

眠い顔は「まだ起きているけど厳しい」、おやすみ顔は「ここで今日は終わる」です。同じ ( ˘ω˘ ) でも、前の言葉が「ねむい」か「おやすみ」かで意味が変わります。おやすみの顔文字はこのページ、月や雲を並べた絵文字は別ページに置いています。

おやすみの文を書いてから、顔を一つ足すと自然です。

眠いとおやすみを一つのページにした理由

「眠い顔文字」と「おやすみ顔文字」は、使う時刻が近く、顔も半分重なります。ページを二つに割ると、同じ ( ˘ω˘ ) が両方に出て、どちらを開けばいいか毎回迷います。会話を閉じる文も、布団の顔も、ここに置いています。

月や星を並べたいだけのときは顔文字が邪魔です。その場合はおやすみの絵文字組み合わせを使ってください。単体の 🌙 はおやすみ絵文字のページです。

送り方

まだ話す

「ねむい」とだけ書いて (っ ̫ -˘)。おやすみと言うと、相手は返事を止めます。

終わりにする

「おやすみ」のあと顔を一つ。布団の AA は長いので、最後の一言より前の会話に向きます。

相手に言う

「いい夢みてね」は自分の眠さではなく、相手を休ませる文です。自分の (¦3[▓▓] とは別にします。

FAQ

眠い顔文字とおやすみ顔文字は同じですか？

顔は似ています。違いは前に置く言葉です。まだ返信するなら眠い、今日は終わりならおやすみ、と書き分けてください。

うとうとの顔はどれですか？

(っ ̫ -˘) や (´-ωก`) のように、目が閉じきっていないものがうとうとです。zzz が付くと、もう寝ています。

月の絵文字もここにありますか？

このページは顔文字です。🌙 や ☁️ を並べた装飾は、おやすみ絵文字の組み合わせページにあります。
